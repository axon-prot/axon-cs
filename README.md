# axon-cs

**C# implementation of the AXON protocol**

This repository will house the C# (`.NET`) implementation of the AXON protocol, a binary, full‑duplex, transport‑agnostic data exchange protocol.

## Overview

The AXON protocol is defined in the [spec repository](https://github.com/axon-prot/spec).

The C# library aims to provide a clean, idiomatic API that mirrors the protocol specification and can be used in any .NET application.

## Building the Project

```bash
cd axon-cs
dotnet build
```

You will need the .NET SDK installed.
